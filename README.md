# 📈 Linear Regression using Scikit-Learn (Python)

A clean and practical implementation of **Linear Regression** using **scikit-learn**, built on a large synthetic dataset to simulate real-world student performance.

This project focuses on **clarity of concepts**, **proper ML workflow**, and **professional project structure**.

---

## 📌 Problem Statement

Predict a student’s exam **Marks** based on the number of **Hours Studied** using supervised machine learning.

---

## 🧠 Concept Used

**Linear Regression**  
A statistical method to model the relationship between a dependent variable (`Marks`) and an independent variable (`Hours_Studied`) using a best-fit line:

\[
y = mx + c
\]

Where:
- `m` = slope (weight)
- `c` = intercept (bias)

---

## 📦 Dataset

- **Type:** Synthetic (Dummy) dataset  
- **Size:** 10,000 records  
- **Generated using:** NumPy  
- **Purpose:** Simulate realistic exam performance with randomness  

### Features
| Column | Description |
|------|------------|
| Hours_Studied | Number of hours studied (0–12) |
| Marks | Exam score (0–100) |

Random noise is added to ensure the data is **not perfectly linear**, mimicking real-world behavior.
